# One More Shiva — Vercel Clean Rebuild

A ground-up mobile-first Next.js rebuild of One More Shiva for Vercel. The production UI uses React/Next.js only — no Streamlit runtime, frame, toolbar, footer, or CSS bridge.

Core destinations: Home, Draft, Guide, Coach, plus the Players board. Coach includes Start/Sit, Waivers, Trades, Lineup Check, Player Watch, Analyst CSV validation, and ESPN league sync.

The app preserves the verified rankings and historical full-PPR datasets while replacing the application code and presentation layer.
